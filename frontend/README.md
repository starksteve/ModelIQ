# ModelIQ Prototype

A dependency-free first prototype for an evidence-backed, governed data modeling workflow.

## Run

Open `index.html` directly in a browser. No package installation or server is required.

## Included

- Business requirement intake
- Simulated enterprise reuse search
- Healthcare standards alignment
- Interactive logical model and entity evidence
- Deterministic design review findings
- SQL, ODCS YAML, and CSV artifact downloads

The current generator uses synthetic deterministic data. A future API can replace the generation function without changing the review workflow.
